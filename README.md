# TTBIK — سوق الخدمات الرقمية المصغّرة (تكلفة تشغيل = 0$)

منصة كاملة لبيع خدمات وأدوات رقمية (بوتات تليجرام، أدوات ذكاء اصطناعي، قوالب أتمتة
ومواقع) مع تجربة تفاعلية حقيقية لكل خدمة، ونظام طلب/دفع/موافقة شبه آلي عبر تليجرام
أو لوحة تحكم داخل الموقع — بدون أي تكلفة استضافة أو اشتراك.

## البنية التقنية (كلها Free Tier)

| الطبقة | الخدمة | لماذا مجانية |
|---|---|---|
| الاستضافة والدومين | **Vercel** (`your-app.vercel.app`) | خطة Hobby مجانية تماماً لمشاريع Next.js |
| قاعدة البيانات | **Supabase** (Postgres) | خطة Free تكفي آلاف الطلبات شهرياً |
| الذكاء الاصطناعي | **Groq API** (نموذج Llama 3) | مفتاح مجاني بدون بطاقة بنكية |
| الإشعارات والموافقة | **Telegram Bot API** | مجاني بالكامل عبر @BotFather |
| بديل الإشعارات | لوحة تحكم داخل الموقع (`/admin`) | لا تحتاج تليجرام إطلاقاً إن أردت |

## الأقسام والخدمات المقترحة (قابلة للتعديل من قاعدة البيانات مباشرة)

1. **🤖 بوتات تليجرام** — بوت رد آلي ($7)، بوت إدارة طلبات ($15)، بوت أسئلة شائعة ($5)
2. **🌐 الترجمة والذكاء الاصطناعي** — مترجم ذكي ($3)، تلخيص نصوص ($4)، مساعد رد على العملاء ($10)
3. **⚙️ الأتمتة والمواقع** — منشئ صفحات هبوط ($12)، قوالب أتمتة مجانية بديلة عن Zapier ($9)، مولد فواتير ($6)
4. **🎨 المحتوى والتصميم بالذكاء الاصطناعي** — منشورات سوشيال ميديا ($3)، كاتب مقالات ($8)، أوصاف منتجات ($5)

كل خدمة تحتوي **تجربة تفاعلية حقيقية** تعمل مباشرة في المتصفح:
- خدمات الذكاء الاصطناعي (`ai_chat` / `content_ai`): تجربة حقيقية عبر Groq API المجاني (محدودة بـ 500 حرف ومعدّل استخدام آمن).
- بوتات تليجرام (`bot_simulator`): محاكاة محادثة تعمل بالكامل في المتصفح دون تكلفة.
- الأتمتة والمواقع (`landing_builder`): معاينة حية تفاعلية تعمل بالكامل في المتصفح.

## دورة الطلب والدفع (شبه آلية)

1. العميل يفتح صفحة الخدمة، يجرّب النسخة المحدودة، ثم يضغط "اطلب الآن".
2. تظهر له بيانات الدفع (IBAN أو USDT) → يحوّل → يضغط "تم الدفع ✅" → يدخل اسمه وبيانات التواصل ورقم/اسم عملية التحويل.
3. يُنشأ الطلب بحالة `pending`، ويصلك تنبيه فوري:
   - في تليجرام: رسالة بكل تفاصيل الطلب مع زرين **[موافقة ✅] [رفض ❌]**.
   - وبالتوازي في لوحة `/admin`: نفس الطلب يظهر مباشرة (تحديث كل 8 ثوانٍ) لمن يفضّل عدم استخدام تليجرام.
4. بمجرد الموافقة (من تليجرام أو من الموقع)، يُسلَّم للعميل تلقائياً رابط/مفتاح الوصول
   (`delivery_content` المعرَّف لكل خدمة)، ويظهر فوراً في صفحة تتبع الطلب `/order/[code]`
   التي تتحدّث كل 5 ثوانٍ دون الحاجة لتحديث الصفحة.

## هيكل المشروع

```
src/
  app/
    page.tsx                     الواجهة الرئيسية (الأقسام والخدمات)
    service/[slug]/page.tsx      صفحة الخدمة (تجربة حية + نموذج الطلب)
    order/[code]/page.tsx        صفحة تتبع حالة الطلب (تحديث تلقائي)
    order/lookup/page.tsx        بحث عن طلب برقم الكود
    admin/page.tsx               لوحة تحكم الإدارة (موافقة/رفض)
    admin/login/page.tsx         تسجيل دخول الإدارة
    api/orders/route.ts          إنشاء طلب جديد + إرسال تنبيه تليجرام
    api/admin/orders/…           جلب الطلبات + الموافقة/الرفض من الموقع
    api/telegram/webhook/route.ts   استقبال ضغطات أزرار تليجرام
    api/demo/ai/route.ts         التجربة الحية عبر Groq API المجاني
  components/                    مكوّنات الواجهة (نموذج الطلب، التجارب الحية)
  lib/                           Supabase / Telegram / منطق الموافقة المشترك
  middleware.ts                  حماية /admin بكلمة مرور
supabase/schema.sql              مخطط قاعدة البيانات + بيانات تجريبية (Seed)
```

## خطوات التشغيل (كل الخطوات هنا مجانية 100%)

### 1) قاعدة البيانات — Supabase
1. أنشئ حساباً مجانياً على supabase.com ومشروعاً جديداً.
2. من SQL Editor نفّذ محتوى الملف `supabase/schema.sql` كاملاً (ينشئ الجداول + سياسات RLS + بيانات تجريبية).
3. من Project Settings → API خذ: `Project URL`, `anon public key`, `service_role key`.

### 2) بوت تليجرام
1. تحدث مع `@BotFather` على تليجرام → `/newbot` → احصل على `TELEGRAM_BOT_TOKEN`.
2. تحدث مع `@userinfobot` لمعرفة `chat_id` الخاص بك → هذا هو `TELEGRAM_ADMIN_CHAT_ID`.
3. اختر أي نص عشوائي ليكون `TELEGRAM_WEBHOOK_SECRET`.
4. بعد النشر على Vercel، فعّل الـ webhook مرة واحدة بزيارة الرابط التالي في المتصفح
   (استبدل القيم بين `<>`):
   ```
   https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=<SITE_URL>/api/telegram/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
   ```

### 3) الذكاء الاصطناعي — Groq (مجاني)
سجّل في console.groq.com (بدون بطاقة بنكية) وأنشئ `GROQ_API_KEY` من قسم API Keys.

### 4) النشر — Vercel
1. اربط المستودع بحساب Vercel (مجاني)، Import Project.
2. أضف كل المتغيرات الموجودة في `.env.example` داخل Vercel → Settings → Environment Variables.
3. Deploy — ستحصل على دومين مجاني `xxx.vercel.app`.

### 5) التشغيل محلياً (اختياري للتجربة)
```bash
npm install
cp .env.example .env.local   # ثم عبّئ القيم
npm run dev
```

## الأمان

- جدول `orders` **غير قابل للقراءة العامة** (لحماية بيانات العملاء)؛ تتبع الطلب يتم عبر
  دالة SQL محصورة (`get_order_public_status`) تُعيد فقط الحقول غير الحساسة.
- كل عمليات الموافقة/الرفض تمر عبر `SUPABASE_SERVICE_ROLE_KEY` من كود السيرفر فقط، ولا تصل أبداً للمتصفح.
- لوحة `/admin` محمية بكلمة مرور عبر `middleware.ts` وكوكي `httpOnly`.
- طلبات الـ Telegram webhook تُتحقّق عبر `secret_token` حتى لا يستطيع أي شخص استدعاء نقطة النهاية.

## ما أحتاجه منك فقط

1. **بيانات استلام الأرباح**: IBAN و/أو عنوان USDT (تُدخل كمتغيرات بيئة `NEXT_PUBLIC_IBAN` / `NEXT_PUBLIC_USDT_ADDRESS`).
2. **تسجيل الحسابات المجانية**: Supabase, Vercel, Telegram Bot (عبر BotFather), Groq — كلها تحتاج بريدك الإلكتروني فقط، لا بطاقة دفع.
3. **جلب المفاتيح المجانية** الناتجة عن الخطوة أعلاه ووضعها في متغيرات البيئة.

كل شيء آخر (الكود، التصميم، منطق الموافقة، التجارب الحية) جاهز بالكامل في هذا المستودع.
