# كتالوج واتساب — WhatsApp Mini-Catalog

الفكرة: أغلب أصحاب المشاريع الصغيرة في السوق العربي يبيعون فعلياً عبر واتساب
(حالة، دردشة)، لكن بدون أي صفحة منظمة لمنتجاتهم. هذا القالب يحوّل قائمة
منتجاتك إلى صفحة كتالوج أنيقة، وكل منتج فيه زر **"اطلب عبر واتساب"** يفتح
محادثة واتساب جاهزة برسالة تحتوي اسم المنتج وسعره تلقائياً — بدون أي سيرفر
أو تكلفة تشغيل.

## التخصيص (دقيقتان فقط)

افتح `index.html` وعدّل كائن `CONFIG` في نهاية الملف:

```js
const CONFIG = {
  storeName: "اسم متجرك",
  tagline: "شعارك التسويقي",
  whatsappNumber: "9665XXXXXXXX", // رقمك بصيغة دولية بدون + أو صفر البداية
  brandColor: "#16a34a",
  products: [
    { name: "...", price: "...", description: "...", image: "رابط صورة المنتج" },
    // أضف منتجات بلا حدود
  ],
};
```

## النشر المجاني

- **GitHub Pages**: ادفع الملف لمستودع GitHub وفعّل Pages — رابط مجاني فوراً.
- **Vercel / Netlify**: اسحب المجلد وأفلته في لوحة النشر (Drag & Drop) — لا يحتاج حساب Git حتى.

شارك الرابط الناتج في حالة واتساب/إنستغرام بدل الصور المتفرقة، ودع عملاءك
يتصفحون ويطلبون مباشرة.
