# مولد الفواتير التلقائي — Invoice Generator

أداة فواتير تعمل بالكامل داخل المتصفح (ملف HTML واحد، بدون سيرفر أو تخزين)، مع
تصدير PDF عبر ميزة الطباعة المدمجة في كل متصفح — بدون أي تكلفة.

## الاستخدام

افتح `index.html` مباشرة في أي متصفح، عدّل بيانات عملك والعميل والبنود، ثم
اضغط "طباعة / حفظ PDF" واختر "حفظ كـ PDF" من نافذة الطباعة.

## النشر (اختياري)

يمكن رفع الملف كما هو على GitHub Pages أو Vercel/Netlify (Drag & Drop) ليصبح
متاحاً كأداة أونلاين لعملائك، أو استخدامه محلياً بدون إنترنت إطلاقاً.
