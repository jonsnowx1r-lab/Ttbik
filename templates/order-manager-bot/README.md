# بوت إدارة الطلبات — Order Manager Bot

نسخة مصغّرة وقائمة بذاتها (بدون قاعدة بيانات، بدون تبعيات) من نفس فكرة منصة
TTBIK نفسها: نموذج طلب بسيط → إشعار فوري في تليجرام بزرين [موافقة ✅][رفض ❌].

## التشغيل

```bash
export TELEGRAM_BOT_TOKEN=xxxxx:yyyyyy
export TELEGRAM_ADMIN_CHAT_ID=123456789   # احصل عليه من @userinfobot
node index.js
```

افتح `http://localhost:3000` لتجربة نموذج الطلب.

## كيف يعمل

- `POST /orders` — يستقبل طلباً جديداً `{ name, contact, note }` ويرسل تنبيهاً فورياً في تليجرام.
- الضغط على "موافقة ✅" أو "رفض ❌" في تليجرام يحدّث حالة الطلب في `orders.json`.
- `GET /orders/:id` — يتيح لصفحة تتبع بسيطة معرفة حالة الطلب.

لا يحتاج أي Webhook أو دومين عام (يستخدم Long Polling)، لذا ينشر مجاناً على
Railway/Render (Web Service — Free tier) أو أي جهاز يعمل باستمرار.

للحصول على نظام كامل بقاعدة بيانات حقيقية ولوحة تحكم وتجارب حية للخدمات، راجع
المنصة الكاملة في جذر هذا المستودع.
