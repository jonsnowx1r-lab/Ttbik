# بوت بيع المساحات الإعلانية — Ad Slot Bot

بوت تليجرام يبيع مساحات إعلانية في قناتك (أو عدة قنوات) بنظام **رصيد مسبق
الدفع (Credit)**، وليس محفظة إيداع/سحب حقيقية.

## لماذا رصيد وليس إيداع/سحب حقيقي؟

بوتات الإعلانات التي تسمح لأي شخص "بالإيداع والسحب" تتحول عملياً لمحفظة
إلكترونية غير مرخّصة في معظم الدول، وهي أيضاً النمط الذي تستخدمه أغلب عمليات
النصب المنتشرة تحت اسم "بوتات إعلانية" على تليجرام. هذا القالب يتجنب المشكلتين
تماماً: أنت تستلم الدفع بنفسك (بنكي/USDT، يدوياً، بنفس أسلوب متجرك) ثم تمنح
العميل رصيداً — تماماً كبطاقة هدايا، لا يوجد فيها "سحب" إطلاقاً.

## التشغيل

```bash
export TELEGRAM_BOT_TOKEN=xxxxx:yyyyyy
export TELEGRAM_ADMIN_CHAT_ID=123456789   # رقمك من @userinfobot
export AD_CHANNELS=@channel1,@channel2    # القنوات التي سيُنشر بها الإعلان (البوت يجب أن يكون Admin فيها)
export AD_COST=5                          # عدد نقاط الرصيد التي يخصمها كل إعلان
node index.js
```

## دورة العمل

1. العميل يدفع لك (خارج البوت، بنفس طريقة الدفع في متجرك).
2. أنت ترسل للبوت: `/credit <user_id> <amount>` لإضافة رصيد للعميل.
3. العميل يرسل: `/ad نص إعلانه هنا`.
4. يصلك تنبيه بزري **نشر ✅** و**رفض ❌**.
5. عند الموافقة: يُخصم الرصيد تلقائياً، ويُنشر الإعلان في كل القنوات المحددة،
   ويُبلَّغ العميل بأن إعلانه أصبح مباشراً.

يعمل بنظام Long Polling، ينشر مجاناً على Railway/Render (Background Worker)
أو أي جهاز يعمل باستمرار — بدون أي تكلفة تشغيل.
