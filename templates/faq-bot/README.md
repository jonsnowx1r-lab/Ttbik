# بوت الأسئلة الشائعة — FAQ Bot

بوت تليجرام يجيب تلقائياً على الأسئلة المتكررة من قائمة تحددها أنت، دون أي تكلفة.

## التشغيل

1. أنشئ بوتاً مجانياً عبر [@BotFather](https://t.me/BotFather) واحصل على التوكن.
2. عدّل ملف `faq.json` وأضف أسئلتك وإجاباتك.
3. شغّل البوت:
   ```bash
   export TELEGRAM_BOT_TOKEN=xxxxx:yyyyyy
   node index.js
   ```

## آلية العمل

يقارن البوت كلمات رسالة العميل بكلمات كل سؤال في `faq.json`، ويختار أقرب تطابق (نسبة تداخل ≥ 40%).
إن لم يجد تطابقاً كافياً يرسل رسالة تحويل للدعم البشري بدل إجابة خاطئة.

يعمل بنظام Long Polling، وينشر مجاناً على Railway/Render (Background Worker) أو أي جهاز يعمل باستمرار.
