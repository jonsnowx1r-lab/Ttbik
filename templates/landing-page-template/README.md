# منشئ صفحات الهبوط — Landing Page Template

قالب صفحة هبوط جاهز (ملف واحد HTML/CSS/JS، بدون أي بناء أو تبعيات) قابل للنشر
المجاني الفوري.

## التخصيص

افتح `index.html` وعدّل كائن `CONFIG` في نهاية الملف:

```js
const CONFIG = {
  name: "اسم مشروعك",
  tagline: "شعارك التسويقي",
  brandColor: "#0284c7",
};
```

عدّل أقسام "لماذا نحن" والأسعار مباشرة داخل الـ HTML حسب الحاجة.

## النشر المجاني (اختر أي طريقة)

- **GitHub Pages**: ادفع الملف لمستودع GitHub وفعّل Pages من الإعدادات — رابط مجاني فوراً.
- **Vercel / Netlify**: اسحب وأفلت المجلد في لوحة التحكم (Drag & Drop Deploy) — لا يحتاج حساب Git حتى.
